# SwagBagger

[![Deploy](https://github.com/tzer0m/SwagBagger/actions/workflows/deploy.yml/badge.svg)](https://github.com/tzer0m/SwagBagger/actions/workflows/deploy.yml)

A torrent magnet submission app with Prowlarr search, qBittorrent download management, and Plex/Jellyfin integration. Built with Blazor Server, authenticated via Pocket ID (OIDC).

Live at [sb.tzer0m.co.uk](https://sb.tzer0m.co.uk).
